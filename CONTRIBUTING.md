# 🤝 Contributing to Wallpapers

Thank you for considering contributing! To keep the repository organized and high-quality, please follow these guidelines when submitting your wallpapers.

## 🗂️ How to Organize

* **Choose the Right Category:** Place the wallpaper in the folder that best fits its theme (e.g., anime wallpapers in the `/anime` folder, landscapes in `/landscape`, etc.).

## 📏 Requirements and Rules

### 1. Size Limit
* **Maximum 10 MB:** Ensure that any image submitted is **under 10 MB**. If the file is too large, please compress it or resize before submitting.

### 2. Naming Convention
* **Use Snake Case:** Do not use spaces or hyphens in file names. Use lowercase letters and separate words with underscores (`_`).
* **Format:** `[wallpaper_name].[extension]`
* *Example:* `sunset_red.jpg` or `neon_cyberpunk.png`

## 🚀 Steps to Contribute

1. **Fork** the project.
2. Add your wallpapers to their respective folders following the rules above.
3. Create a **Pull Request**.

## 💡 Suggesting New Folders

If your wallpaper does not fit into any of the existing folders, don't worry! Create an issue or mention it in your Pull Request so we can debate the creation of a new category.
